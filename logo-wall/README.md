# Logo wall

Блок «Клієнти»: логотипи плавно міняються через блюр хвилею зліва направо, адаптивна сітка, плавний перехід між брейкпоінтами.

## Файли

| Файл | Що це |
|---|---|
| `logo-wall.css` | стилі блоку |
| `logo-wall.js` | клас `LogoWall`, без залежностей |
| `logos/*.svg` | по одному файлу на логотип |
| `demo.html` | приклад підключення |
| `playground.js` | опис для плейграунду: контроли, пресети, сніпет. На сайт не потрібен |

## Підключення

```html
<link rel="stylesheet" href="logo-wall.css">

<section id="clients" aria-label="Our clients"></section>

<script src="logo-wall.js"></script>
<script>
  new LogoWall('#clients', {
    logos: ['logos/comfy.svg', 'logos/synevo.svg', 'logos/klo.svg'],
    rows: 2,
  });
</script>
```

Усі інші опції мають дефолти. Повний список з коментарями у шапці `logo-wall.js`. Плейграунд показує готовий сніпет з будь-якими підкрученими значеннями.

## Як додати або замінити логотип

1. Експортуй логотип з Figma як SVG. Він має бути монохромним (колір задає блок) і мати `viewBox`, з нього береться розмір.
2. Бажано прогнати через [SVGO](https://svgo.dev) або svgomg.net, файли з Figma вдвічі важчі, ніж треба. `viewBox` не видаляти.
3. Поклади файл у `logos/`. Назва файлу стає accessible name: `brain-tank.svg` → «Brain Tank». Якщо треба інша назва, передай об'єкт: `{ src: 'logos/1plus1.svg', name: '1+1' }`.
4. Додай шлях у масив `logos` в ініціалізації.

Щоб прибрати логотип, видали шлях з масиву. Файл можна залишити.

Скільки логотипів видно одночасно: `rows × columns` для поточного брейкпоінта (за замовчуванням 10 на десктопі, 6 на мобільному). Решта чекає в резерві і заходить хвилями. Що більше лого в резерві, то рідше повторюються.

## Брейкпоінти

Блок реагує на ширину свого контейнера, не вікна.

| Ширина контейнера | Колонок | Висота ряду | Масштаб лого | Відступи |
|---|---|---|---|---|
| ≥ 960 | 5 | 64 | 1 | 40 / 120 |
| 600 до 959 | 4 | 56 | 0.88 | 32 / 48 |
| 360 до 599 | 3 | 48 | 0.74 | 24 / 16 |
| < 360 | 2 | 48 | 0.8 | 20 / 12 |

Кількість колонок міняється через опцію `columns`, решта у `logo-wall.css`.

## Що ще варто знати

- Автоплей працює тільки поки блок на екрані і вкладка активна.
- При `prefers-reduced-motion` автоплею немає, лого просто показані.
- Висота блоку зарезервована ще до завантаження SVG, тому layout shift немає.
- На сайт беруть `logo-wall.css` + `logo-wall.js` і свої SVG. Плейграунд: `../index.html`, вкладка «S : Clients».
