Border beam

Анімоване веселкове світло по межі елемента: різка обводка, м'яке внутрішнє сяйво і розмитий bloom, усі три крутить одна CSS-змінна. Чистий CSS + маленький контролер, без залежностей. Порт libraries.dev/beam.

Dot sphere

3D-сфера з точок на звичайному canvas, без WebGL: повільно обертається, тягнеться за курсором, крутиться перетягуванням з інерцією. Шість розкладок точок, один файл без залежностей.

Вигляд

Код

Файли лежать у dot-sphere/: sphere.js, demo.html, README.md. Увесь ефект це один файл. Полотно малює свій фон саме, background: 'transparent' кладе сферу на будь-яку підкладку. Точки не сортуються за глибиною, а розкладаються по 20 кошиках і кожен кошик малюється одним fill(), тому 20 000 точок тримають 60 fps.
