# Dot sphere

3D-сфера з точок на звичайному canvas, без WebGL і без матричних бібліотек: повільно обертається, тягнеться за курсором, крутиться перетягуванням з інерцією. Шість розкладок точок, один файл без залежностей.

## Файли

| Файл | Що це |
|---|---|
| `sphere.js` | увесь ефект: `DotSphere.create(canvas, options)` |
| `demo.html` | приклад підключення |

Плейграунд спільний з рештою блоків: `../index.html`, вкладка «Dot sphere». Збирається одним скриптом: `python3 build-playground.py` з кореня.

## Підключення

```html
<canvas id="sphere" style="width: 480px; height: 480px"></canvas>

<script src="sphere.js"></script>
<script>
  const s = DotSphere.create(document.getElementById('sphere'), {
    style: 'stipple',
    count: 5200,
    color: '#141414',
    background: '#f4f4f2',
    speed: 0.13,
  });
</script>
```

Полотно саме стежить за своїм розміром (`ResizeObserver`) і саме малює фон, тож розтягуйте його як завгодно. `background: 'transparent'` кладе сферу на будь-яку підкладку. Плейграунд показує готовий сніпет з будь-якими підкрученими значеннями.

## Розкладки

| `style` | Що це |
|---|---|
| `stipple` | Рівномірні точки по поверхні (розподіл Фібоначчі). Той самий «відбиток пальця» з муарових спіралей. |
| `orbits` | Великі кола у випадкових орієнтаціях, сплутані орбіти. |
| `grid` | Паралелі й меридіани, викладені точками. |
| `spiral` | Одна суцільна спіраль від полюса до полюса, клубок нитки. |
| `cloud` | Об'ємна оболонка: точки не на поверхні, а в шарі під нею. |
| `mesh` | Розріджені вузли плюс лінії між сусідами, сфера-мережа. |

## Як це працює

Точки живуть на одиничній сфері, щокадру проходять три обертання (yaw → pitch → статичний нахил осі) і одне перспективне ділення. Глибина керує і розміром, і прозорістю точки, саме це дає відчуття об'єму.

Головна оптимізація: точки не сортуються за глибиною, а розкладаються по 20 «кошиках» глибини, і кожен кошик малюється одним `fill()`. Тому 20 000 точок тримають 60 fps на звичайному ноутбуці.

## Реакція на курсор

- Наведення: сфера плавно доводиться до кута, що відповідає позиції курсора (`pointer` сила, `damping` пружність).
- Перетягування: крутить сферу напряму, після відпускання лишається інерція (`friction`).
- Курсор пішов з полотна: сфера так само плавно повертається у базове положення.

## Основні опції

| Опція | Типово | Що робить |
|---|---|---|
| `style` | `'stipple'` | Розкладка точок (таблиця вище). |
| `count` | `5200` | Кількість точок, максимум 20000. |
| `seed` | `7` | Перекидає випадкові розкладки (`orbits`, `cloud`). |
| `radius` | `0.78` | Розмір сфери відносно полотна. |
| `dotSize` | `1.15` | Розмір точки в пікселях. |
| `perspective` | `4.5` | Відстань камери в радіусах: більше — пласкіше. |
| `depthFade` / `depthScale` | `0.55` / `0.45` | Наскільки задня півсфера блідне і зменшується. |
| `speed` / `direction` / `tilt` | `0.13` / `1` / `-0.28` | Автообертання, рад/с. |
| `pointer` / `damping` | `0.55` / `0.055` | Паралакс за курсором. |
| `drag` / `friction` | `true` / `0.94` | Розкручування перетягуванням та інерція. |
| `color` / `background` | `#141414` / `#f4f4f2` | `background: 'transparent'` — прозорий фон. |
| `jitter` | `0` | Радіальний шум поверх будь-якої розкладки. |

Плюс параметри під конкретний стиль: `rings`, `gridLat`, `gridLon`, `turns`, `thickness`, `linkDist`, `lineWidth`. Повний список з коментарями у шапці `sphere.js`.

## API

```js
s.set('style', 'orbits');            // одна опція
s.setOptions({ speed: 0.3, tilt: 0 });
s.pause(); s.resume();               // заморозити обертання
s.stop();  s.play();                 // зупинити / запустити цикл малювання
s.destroy();                         // зняти слухачі та спостерігач розміру
```

## Що ще варто знати

- При `prefers-reduced-motion: reduce` обертання зупиняється, сфера лишається статичною. Вимкнути: `DotSphere.create(el, { respectReducedMotion: false })`.
- Ховаючи полотно (інший таб, згорнута секція), викликайте `s.stop()`, інакше `requestAnimationFrame` крутиться марно. Плейграунд робить саме так.
- Полотно обмежене 2048 px на сторону і ~4.2 Мпкс у буфері, щоб на retina-екранах не розростатися без міри.
