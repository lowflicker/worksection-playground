# Float actions

Кнопки support (чат) і ringostat (дзвінок) поверх сайту. 56px, `#4a83f4`, hover scale 1.05, як у Figma. Модуль відповідає тільки за поведінку кнопок на сторінці. Що за ними, він не знає: клік віддає керування сторонньому віджету, який ти підвантажуєш на вимогу.

## Поведінка

| Момент | Що відбувається |
|---|---|
| Поява | Після `enterDelay` (або `showAfter` px скролу) кнопки вискакують знизу з overshoot, нижня перша, верхня за 90 мс |
| Скрол | Після `foldAfter` px униз верхня кнопка заїжджає за нижню і визирає з-під неї на `peek` px темнішим краєм, як стос. Розкладається після `foldAfter` px угору, біля верху сторінки або при наведенні. Тільки напрямок, без таймерів, тому скрол маленькими кроками не смикає стан. `unfoldDelay` вмикає ще й розкладання після паузи, за замовчуванням вимкнено |
| Наведення | Scale 1.05 in-out-cubic, тінь трохи глибша, через `labelDelay` зліва вилітає підпис із хвостиком. Іконка чату підіймається на 1px, телефон робить один дзвінок. Лише на пристроях із hover |
| Клік | Подія `fa:action` і `onAction(id, fa)`. Далі три стани, які перемикаєш сам: `loading` (іконка тьмяніє, по обідку крутиться дуга), `active` (іконка обертається в хрестик, інші кнопки відходять), `idle` |
| Хрестик або Esc | `fa:close` і `onClose(id, fa)`: закриваєш віджет і викликаєш `fa.idle(id)` |
| Нудж | Якщо `nudgeAfter` мс ніхто не чіпав: перша кнопка робить один м'який bounce, двічі пускає кільце, поруч з'являється бульбашка з повідомленням і хвостиком. Наведення на бульбашку зупиняє її таймер, хрестик на ній закриває, клік по ній дорівнює кліку по кнопці. Спрацьовує один раз |
| Футер | Елементи з `data-fa-avoid` кнопки не перекривають: `avoidMode: 'lift'` садить їх на верхній край футера і веде разом зі скролом, `'hide'` ховає, `'none'` нічого не робить |
| Мобільний | Під `compactBelow` кнопки 48px, відступ 16px, без підписів, враховано `safe-area-inset-bottom`. Перший тап по складеному стосу тільки розкладає його, дія не спрацьовує. Поки віджет відкритий, усі наші кнопки сховані (`whenActiveCompact: 'all'`), бо мобільні віджети відкриваються на весь екран із власним хрестиком і лежать вище за нас. Bounce-скрол iOS не смикає стос, позиція обрізається до реального діапазону |

`whenActive` каже, що роблять інші кнопки, поки віджет відкритий: `'others'` відходять (за замовчуванням), `'all'` ховаються всі, бо віджет має власний хрестик, `'none'` лишаються.

## Файли

| Файл | Що це |
|---|---|
| `float-actions.css` | стилі |
| `float-actions.js` | клас `FloatActions`, без залежностей, іконки з Figma вшиті |
| `demo.html` | приклад підключення з імітацією віджета |

Плейграунд спільний з іншими блоками: `../index.html`, вкладка «Float actions». Сайт і сторонній віджет там скелети. Збирається: `python3 build-playground.py`.

## Підключення

```html
<link rel="stylesheet" href="float-actions.css">

<footer data-fa-avoid>…</footer>

<script src="float-actions.js" defer></script>
<script>
  new FloatActions(document.body, {
    actions: [
      { id: 'support', icon: 'chat', label: 'fa.support.label' },
      { id: 'ringostat', icon: 'phone', label: 'fa.ringostat.label' },
    ],
    t: key => i18n.t(key),                   // або словник { 'fa.support.label': '…', … }
    onAction(id, fa) {
      fa.loading(id);
      loadWidget(id).then(widget => {        // твій лоадер: Intercom, Crisp, Ringostat…
        widget.open();
        fa.active(id);
        widget.onClose(() => fa.idle(id));   // якщо віджет закрили зсередини
      });
    },
    onClose(id, fa) {
      widgets[id].close();
      fa.idle(id);
    },
  });
</script>
```

Усі інші опції мають дефолти, повний список у шапці `float-actions.js`. Плейграунд показує готовий сніпет з підкрученими значеннями.

## Локалізація

Модуль не містить жодного тексту напряму. `label`, `nudgeMessage` і `strings.dismiss` це ключі, які проходять через опцію `t`: функцію `key => string` (підключаєш i18n сайту) або словник. Без `t` ключ показується як є. Дефолтні ключі: `fa.support.label`, `fa.ringostat.label`, `fa.nudge.message`, `fa.dismiss`. Зміна мови на льоту: `fa.setOptions({ t: newDict })`, тексти перемальовуються без перезбирання кнопок.

## Що ще варто знати

- Модуль важить ~9 KB gzip і не блокує рендер. Важкий віджет вантажиться тільки по кліку, тому відвідувач, який не відкриє чат, не платить за нього нічого.
- У сторонніх віджетів є власні лаунчери в тому ж куті. Вимкни їх у налаштуваннях віджета (Intercom: `hide_default_launcher`, Crisp: `$crisp.push(["do", "chat:hide"])`), інакше буде дві кнопки.
- Порядок в `actions` зверху вниз, нижня кнопка стає якорем, за який складаються інші. Кнопок може бути одна або більше двох.
- Кнопки монтуються в `body` і фіксуються до вікна. Щоб змонтувати в прокручувану рамку, передай `fixed: false`, `scroller: element` і саму рамку як root (так у плейграунді).
- При `prefers-reduced-motion` немає overshoot, кілець, bounce і дзвінка іконки, стани перемикаються миттєво.
- Доступність: `aria-label`, `aria-pressed`, `aria-busy` під час завантаження, фокус-кільце, Esc.
- Методи: `loading(id)`, `active(id)`, `idle(id)`, `nudge()`, `show()`, `hide()`, `fold()`, `unfold()`, `setOptions(patch)`, `reset()`, `destroy()`.
- Події на шарі: `fa:show`, `fa:action`, `fa:close`, `fa:nudge`.
