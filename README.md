# Worksection playground

Блоки промосайту Worksection і візуальні ефекти для UI: крутиш параметри, бачиш результат, копіюєш готовий код. Кожен модуль це чистий HTML + CSS + vanilla JS без залежностей і без збірки, готовий до вставки на сайт.

Онлайн: https://lowflicker.github.io/worksection-playground/

| Вкладка | Модуль | Що це | Що брати на сайт |
|---|---|---|---|
| S : Clients | [`logo-wall/`](logo-wall) | логотипи клієнтів, свап через блюр хвилею | `logo-wall.css`, `logo-wall.js`, свої SVG |
| S : Short answer | [`short-answer/`](short-answer) | вердикт і варіанти, зв'язані живими конекторами | `short-answer.css`, `short-answer.js` |
| Float actions | [`float-actions/`](float-actions) | кнопки support і ringostat поверх сайту | `float-actions.css`, `float-actions.js` |
| Border beam | [`border-beam/`](border-beam) | веселкове світло по межі елемента, чистий CSS | `beam.css`, `beam.js` |
| Dot sphere | [`dot-sphere/`](dot-sphere) | 3D-сфера з точок на canvas, реагує на курсор | `sphere.js` |
| S : Hero | [`hero-section/`](hero-section) | хіро з вкладками і двома скріншотами, на телефоні тап міняє головний | `hero.css`, `hero.js`, своя розмітка і скріншоти |
| S : Header | [`site-header/`](site-header) | шапка worksection.com: липка пігулка, стискається на скролі, бургер і лист на вузькому | `header.css`, `header.js`, своя розмітка |
| C : Button | [`site-button/`](site-button) | кнопки сайту (дзеркало `.btn` з worksection.com) і промінь border-beam у моно на головній | лише `.btn-beam` з `button.css` + `beam.css`, `beam.js` |

## Для розробника

У теці модуля лежить усе, що потрібно:

| Файл | Що це |
|---|---|
| `*.css`, `*.js` | сам модуль. Без залежностей, підключається двома тегами |
| `demo.html` | мінімальна сторінка з модулем: відкрий у браузері, подивись, як він живе сам по собі |
| `README.md` | опції, API, події, як воно працює всередині і на що звернути увагу |
| `playground.js` | опис модуля для плейграунду. На сайт не потрібен |

Найшвидший шлях: відкрити плейграунд, підкрутити параметри, натиснути **Код** і скопіювати сніпет. У сніпеті вже підставлені поточні значення, а рядки, що відрізняються від дефолтів, підсвічені. Там же вкладки з повним джерелом файлів і посилання на README модуля.

Кнопка **Посилання** пакує поточні налаштування в URL, тож дизайнер може передати саме той стан, який погодили.

## Плейграунд

`index.html` це статична сторінка: підключає оболонку з `playground/` і модулі як є, ніякої збірки. Локально треба будь-який сервер, бо модулі підтягують файли:

```bash
python -m http.server 5174
```

Оболонка (`playground/shell.css`, `playground/shell.js`) універсальна і не знає про конкретні модулі. Модуль реєструється з власного `playground.js` через `Playground.register({...})` і описує: дефолтний стан, контроли панелі, пресети, як змонтувати демо та як застосувати зміни, сніпет для вкладки коду. Повний контракт у шапці `playground/shell.js`.

Оболонка дає кожному модулю однаковий набір інструментів: паузу, сповільнення анімацій, ширину рамки з пресетами, масштаб, сітку 8 px і напрямні, лічильник FPS, збереження і посилання, світлу й темну тему, гарячі клавіші (кнопка `?` у топбарі), мобільну шторку.

### Новий модуль

1. Тека `my-block/` з `my-block.css`, `my-block.js`, `demo.html`, `README.md`.
2. `my-block/playground.js` з `Playground.register({...})`, за зразком сусідніх.
3. Два рядки в `index.html`: стилі модуля в `<head>`, скрипт модуля і `playground.js` в кінці `<body>`.
